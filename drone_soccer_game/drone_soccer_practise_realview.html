觸控搖桿操控

  • 左搖桿：上推上升／下拉下降，左右推偏航旋轉
  • 右搖桿：前後左右移動
  • 上方按鈕可一鍵起飛／降落

鍵盤控制說明

  • W : 增加油門，長按持續上升，放開定高懸停
  • S : 減少油門，長按持續下降，放開定高懸停
  • A : 逆時針旋轉 (Yaw Left)
  • D : 順時針旋轉 (Yaw Right)
  • ↑ : 前進 (Pitch Forward)
  • ↓ : 後退 (Pitch Backward)
  • ← : 向左滾轉 (Roll Left)
  • → : 向右滾轉 (Roll Right)
  • C : 切換鏡頭視角（追蹤 / 定中 / 定左 / 定右 / 座艙 / 自由）
  • T : 一鍵起飛 (平穩上升至 2.2 米並定高)
  • L : 一鍵降落 (平穩降落至中心並熄火)
  • R : 重置無人機 (回到場地中央)
  • M : 靜音切換
  • Space / Ctrl : 油門升 / 降 (備用鍵，同 W/S)
